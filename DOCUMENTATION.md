## Модуль: src/data/loadMapData.js

### Назначение
Загружает GeoJSON-файл по указанному URL и возвращает распарсенные данные (объект FeatureCollection).

### Почему так
fetch() — асинхронный запрос, поэтому функция помечена async и использует await
для ожидания сначала самого HTTP-ответа, потом — распарсенного тела ответа (.json()).

### API
loadMapData(url: string) → Promise<Object>

### Использование
import { loadMapData } from './data/loadMapData.js';
loadMapData('/data/lopatino.geojson').then(geojson => { ... });

## Обновление: поддержка нескольких типов геометрии

getBounds() и renderMap() изначально работали только с Polygon (здания).
После расширения GeoJSON данными о дорогах (LineString) и точках интереса (Point)
через Overpass Turbo, обе функции переписаны с использованием switch(geometry.type)
для раздельной обработки каждого типа, с общей вспомогательной функцией
updateBounds(lng, lat) внутри getBounds, чтобы не дублировать логику сравнения.

## Задача 14: Обработка прокрутки мыши (Зум карты)

Выжимка: Нам нужно научить класс Camera изменять своё свойство this.zoom при прокрутке колесика, а в main.js перехватывать событие wheel на холсте, обновлять камеру и мгновенно перерисовывать карту, чтобы пользователь увидел плавный зум.

📚 Теория: Событие wheel и перерисовка Canvas
Когда пользователь крутит колесико мыши (или делает жест свайпа двумя пальцами на тачпаде), браузер генерирует событие 'wheel'. У этого события есть очень важное свойство — event.deltaY (число, показывающее, куда крутится колесико):

Если deltaY меньше нуля (отрицательное) — колесико крутят вверх (пользователь хочет приблизить карту).
Если deltaY больше нуля (положительное) — колесико крутят вниз (пользователь хочет отдалить карту).

Поскольку Canvas — это статичная картинка, он не умеет сам по себе увеличивать изображение. Чтобы сделать зум, нам нужно:

1. Перехватить прокрутку.
2. Изменить число camera.zoom (например, умножить его или прибавить шаг).
3. Полностью перерисовать карту с новыми параметрами! Для этого нам нужно заново сгенерировать функцию project и вызвать renderMap.

Указания к действию: Шаг 1. Пишем метод зума в Camera.jsДавай начнем с файла src/core/Camera.js. Прямо внутрь класса Camera (ниже твоего конструктора) нужно добавить новый метод — назови его, например, handleZoom(deltaY).Что этот метод должен делать внутри себя:Он должен проверять знак deltaY.Если deltaY < 0, мы приближаем карту: увеличиваем this.zoom (например, умножаем его на коэффициент плавности 1.1 или прибавляем 0.1).Если deltaY > 0, мы отдаляем карту: уменьшаем this.zoom (например, делим на 1.1 или вычитаем 0.1).Важный лайфхак: Обязательно добавь ограничитель (минимум), чтобы this.zoom случайно не стал равен нулю или ушёл в минус, иначе карта перевернётся или исчезнет (например, if (this.zoom < 0.1) this.zoom = 0.1).
